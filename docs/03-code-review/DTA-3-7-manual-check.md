## 왜 이 문서가 필요한가

위젯 탭 동작은 **자동 검증이 닿지 않는다.** 시뮬레이터·단위 테스트로는
"탭이 실제로 AppIntent 를 부르는지", "위젯이 즉시 다시 그려지는지"를 알 수 없다.
그래서 이 항목만 사람이 확인하고 그 결과를 여기 적는다.

자동으로 확인된 범위는 [DTA-3-7-review.md](DTA-3-7-review.md) 에 있다.

## 아직 확인되지 않은 항목

사용자가 확인한 것은 **"위젯에서 완료가 된다"** 까지다. 아래는 별개의 관찰이
필요하며, 확인 전까지 동작한다고 적지 않는다.

| 항목 | 확인 방법 |
| --- | --- |
| 완료 후 **다음 항목이 올라오는지** | 위젯에 3건 이상 보이는 상태에서 맨 위를 완료. 빈칸이 남지 않고 아래가 당겨져야 한다 |
| 앱 없이 **연속 완료** | 앱을 열지 않은 채 3건 연속 완료. Flutter 가 10칸을 저장하므로 8건까지 가능해야 한다 |
| 앱 재진입 시 **DB·서버 반영** | 완료 후 앱을 열고 목록 확인 → 완료 상태여야 함. 웹/다른 기기에서도 완료로 보여야 함 |
| **진행률 표시** | 오늘 항목을 완료하면 `1/3` → `2/3`. 미래 항목을 완료해도 분모를 넘지 않아야 함 (`3/2` 금지) |
| 완료 → 미완료 **되돌아감 없음** | 앱에서 완료 → 앱 재진입 → 여전히 완료여야 함 (`decideSync` 가드) |
